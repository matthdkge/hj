# 🏛️ 학과별 복합 다중게시판 시스템 (Department Composite Multi-Board System)

대학 내 **학과(운영 공간)별로 공지사항과 다양한 의견을 안전하게 공유**할 수 있도록 설계된 **멀티 공간 기반 복합 다중게시판 웹 애플리케이션**입니다.

---

## ✨ 주요 특징 및 핵심 설계

### 1. 학과별 운영 공간(Space) 분리 및 타 학과 접근 차단
- **공간별 다중게시판 운영**: `컴퓨터공학과`, `디자인학과`, `경영학과` 등 학과마다 독립된 운영 공간을 가지며, 각 공간 내부에 목적에 맞는 여러 게시판(`학과 공지사항`, `건의 및 의견 나눔`, `자유 소통·Q&A`, `학과 양식·자료실`)을 동적으로 개설·운영할 수 있습니다.
- **공간 간 접근 차단 (`403 Access Denied`)**: 특정 학과에 소속되지 않은 외부 학과 구성원은 타 학과의 게시판 목록, 게시글, 댓글, 첨부파일, 검색 결과에 접근할 수 없도록 철저히 격리됩니다.
- **과별 전담 조교 권한 격리**: 각 학과마다 전담 조교(`SPACE_ADMIN`)가 배치되어 있으며, **조교는 오직 자기 소속 학과에 대해서만 관리 권한**을 가집니다(타 학과 접근 및 관리 불가).

---

### 2. 5단계 사용자 역할(RBAC) 및 직책 인증 코드 회원가입
게시판 구성원은 공간 내에서 아래 **5가지 역할**로 구분되며, 회원가입 시 **소속 학과 선택 + 특정 직책 인증 코드 입력**을 통해 조교·모더레이터·교수로 즉시 가입할 수 있습니다.

| 구분 | 역할 코드 | 역할 명칭 | 직책 예시 | 컴퓨터공학과 코드 | 디자인학과 코드 | 경영학과 코드 | 공통 인증 코드 | 주요 권한 |
| :---: | :--- | :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **①** | `READER` | **게시글을 읽는 사람** | 신입생 / 준회원 | 코드 불필요 | 코드 불필요 | 코드 불필요 | 코드 불필요 | 게시글·댓글 열람, 검색, 첨부파일 다운로드 (작성 불가) |
| **②** | `WRITER` | **게시글·댓글을 작성하는 사람** | 일반 재학생 | 코드 불필요 | 코드 불필요 | 코드 불필요 | 코드 불필요 | 일반 게시글·댓글 작성, 본인 글 수정·삭제, 추천 및 신고 |
| **③** | `NOTICE_MANAGER` | **공지사항을 등록하는 사람** | 학과 교수 | `CSE-PROF` | `DSN-PROF` | `BIZ-PROF` | `PROF-2026` | 일반 작성 권한 + 공지 전용 게시판 작성 및 상단 고정 공지 등록 |
| **④** | `MODERATOR` | **부적절한 게시물을 관리하는 사람** | 모더레이터 / 학생회 | `CSE-MOD` | `DSN-MOD` | `BIZ-MOD` | `MOD-2026` | 타인의 부적절한 게시글·댓글 블라인드/강제 삭제, 신고 처리, 작성 제한 |
| **⑤** | `SPACE_ADMIN` | **게시판·운영공간을 관리하는 사람** | **학과 전담 조교** | `CSE-ADMIN` | `DSN-ADMIN` | `BIZ-ADMIN` | `ADMIN-2026` | **자기 학과 내** 게시판 생성·수정·삭제, 구성원 역할 변경 및 강제 퇴출 |

### 3. 8대 필수 기능 및 사용자/관리자 요구사항 구현
1. **회원가입 및 로그인**: 학과 선택 및 직책 인증 코드(`ADMIN-2026`, `MOD-2026`, `PROF-2026` 등) 기반 회원가입, 역할별 원클릭 체험 전환 바 제공
2. **게시글 조회**: 게시판별 필터링, 상단 고정 공지사항 표시, 조회수 자동 증가, 최신순/추천순/조회순 정렬
3. **게시글 작성·수정·삭제**: 제목, 내용, 작성자(익명 선택 가능), 작성일시, 수정일시 자동 기록 및 첨부파일 관리
4. **댓글 시스템**: 댓글 작성, 본인 댓글 인라인 수정·삭제, 관리자의 부적절 댓글 블라인드 및 강제 삭제
5. **파일 첨부 및 다운로드**: 다중 첨부파일 업로드(Base64 영구 저장) 및 소속 학과 구성원 전용 다운로드
6. **통합 및 조건별 검색**: `제목+내용`, `제목`, `내용`, `작성자` 키워드 검색 및 말머리(카테고리) 필터링
7. **실시간 인앱 알림**: 내 글에 댓글 등록, 추천(공감) 발생, 새 학과 공지 등록, 블라인드 등 관리 조치 시 실시간 알림 벨 표시
8. **게시글 추천(공감)**: 학과 건의사항 및 공지사항에 대한 추천 토글 및 추천순 인기 의견 정렬
9. **내 게시글·댓글 모아보기**: 일반 사용자가 자신이 작성한 모든 게시글과 댓글을 한눈에 조회하고 즉시 수정·삭제 가능
10. **공간·게시물 관리 센터**:
    - 게시판 목적에 맞지 않는 게시글을 다른 게시판으로 즉시 이동
    - 신고 접수 내역 확인, 부적절 게시물 블라인드(숨김) 처리 및 문제 사용자 `읽기 전용(READER)` 강등/강퇴

---

### 4. 데이터 영구 저장 (Persistence)
브라우저를 껐다가 다시 켜거나 새로고침해도 모든 데이터가 그대로 유지되도록 **3중 영구 저장소 엔진**이 적용되어 있습니다.
- `LocalStorage` (`DEPT_MULTIBOARD_DB_V3`)
- `IndexedDB` (`DeptMultiBoardIndexedDB` — 대용량 첨부파일 포함 영구 보존)
- JSON 파일 전체 백업 다운로드 및 복원 기능 지원

## 🚀 실행 방법

별도의 복잡한 빌드 과정 없이 바로 실행할 수 있습니다.

1. **브라우저에서 바로 열기**
   - 프로젝트 폴더의 [`index.html`](./index.html) 파일을 더블클릭하여 웹 브라우저(Chrome, Edge 등)로 바로 엽니다.
2. **로컬 서버 스크립트로 실행하기 (선택)**
   - PowerShell에서 아래 명령어를 실행하면 로컬 서버(`http://localhost:8080`)와 파일 DB 동기화가 함께 실행됩니다.
   ```powershell
   .\start-server.ps1
   ```
